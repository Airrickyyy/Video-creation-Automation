# 02 — Script

```
Write the narration for a YouTube Short about: {{IDEA + HOOK + PAYOFF from step 1}}.

Rules:
- 60–100 spoken words (about 15–30 seconds with our voice).
- Sentence 1 is the hook: the most surprising claim, in under 12 words. No greeting,
  no "did you know", no channel name.
- Leave a question open in the first 5 seconds that only the last line answers.
- One idea per sentence. Short, concrete sentences that are easy to read as big captions.
  Every sentence should be something we can SHOW on screen.
- Write numbers the way they should be spoken ("four billion", not "4,000,000,000").
- End on the strongest line. If possible, make the last line lead back into the first
  so the video loops.
- No calls to action like "like and subscribe".
- Don't exaggerate. Every factual claim must be true as stated.

Output, in this order:
1. SCRIPT: only the spoken words, one sentence per line.
2. FACT CHECK: a table of every factual claim → a reliable source URL that supports it
   (prefer primary sources: NASA, museums, encyclopedias, peer-reviewed papers)
   → confidence (high/medium/low). Flag anything you aren't sure of instead of guessing.
3. TRIM: a version cut by about 30% in case the first is too slow. Say which you'd use.
```

After you get the script: open the source links for anything marked medium/low and fix or
cut those lines before using it. Save only the spoken words as `script.txt`.
