# 03 — Visuals

```
Here is the narration script for a vertical (9:16) YouTube Short, one sentence per line:

{{SCRIPT}}

Make a shot list: one visual per 1–2 sentences, 4–7 visuals in total, in script order.
The visual should show what the narrator is saying at that moment. The first shot must be
the most striking image, because it carries the hook.

For each shot give:
- Which line(s) it covers
- What should be on screen
- Where to get it LEGALLY for free, with a search term or a direct link if you know one:
  NASA Image Library (images.nasa.gov, generally public domain), Library of Congress
  (public domain collections), Wikimedia Commons (only files marked public domain or CC0/CC-BY),
  Pexels/Pixabay (free license). Never suggest screenshots from other videos, movies,
  news sites, or Reddit.
- License + the credit line we must keep
- Whether it will survive a center crop to 9:16 (the important part should be in the middle)
```

Save the files as `visuals/01.jpg`, `02.jpg`, ... in script order, and record each one in
`sources.json`:

```json
{
  "01.jpg": {"title": "...", "url": "...", "credit": "...", "license": "..."}
}
```
